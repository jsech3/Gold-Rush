1. What You're Building

Gold Rush is an automated job finder that:

  • Monitors two sources 24/7:
    • Your Gmail job alerts (LinkedIn, Indeed, Glassdoor)
    • JSearch API (aggregates LinkedIn, Indeed, Glassdoor, ZipRecruiter)
  • Finds jobs posted in last 24 hours
  • Scores each job 0-100 based on:
    • Title match (40 pts) - "Technical Product Manager" = perfect match
    • Salary (25 pts) - $150k+ = high score
    • Freshness (20 pts) - Posted <6 hours = maximum points
    • Company quality (15 pts) - Stripe, Figma, Notion = top tier
  • Emails you 5-10 "golden jobs" every morning at 7am
  • Stores everything in local database (no cloud, you own the data)

Example: What You'll Receive Every Morning

Email Subject: 🥇 5 Golden Jobs Found - February 7, 2026

Email Content:

  • 🥇 Platinum Jobs (90+ score): Technical Product Manager @ Figma - $165k-$220k - Posted 4 hours ago
  • 🥈 Gold Jobs (75-89 score): Product Manager, Analytics @ Notion - $150k-$200k - Posted 11 hours ago
  • Direct "Apply Now" buttons for each job
  • Why each job is golden (exact match, fresh, great company)

The Competitive Edge

Without Gold Rush: You search at 6pm → Job posted at 9am → 150 people already applied → You're buried

With Gold Rush: Job posted at 9am → Script finds it at 7pm → You apply at 7:10pm → You're applicant #15-30

Result: Being in first 30 applicants increases callback rate by 5-10x

3. Setup Steps

1 Install Dependencies 5 minutes

What you're doing:

Installing Python packages that Gold Rush needs to work.

Commands to run:

cd "$HOME/Job Searching" pip3 install requests beautifulsoup4 python-dotenv

Expected output:

You'll see "Successfully installed..." messages for each package.

Tip: If you get "command not found: pip3", try pip instead of pip3.
2 Get Gmail App Password 10 minutes

Why you need this:

Google doesn't allow apps to use your regular Gmail password for security. You need to generate a special "app password" that Gold Rush will use to read your job alert emails and send you digests.

Steps:

  1. Go to myaccount.google.com/apppasswords
  2. If you don't have 2-Factor Authentication enabled:
    • You'll need to enable it first
    • Go to myaccount.google.com/security
    • Click "2-Step Verification" → Follow the setup
    • Use your phone number (easiest method)
  3. Once 2FA is enabled:
    • Go back to App Passwords page
    • Under "Select app" → Choose Mail
    • Under "Select device" → Choose Mac
    • Click Generate
  4. Copy the 16-character password
    • Format looks like: xxxx xxxx xxxx xxxx
    • SAVE THIS - you'll paste it in Step 3
    • You won't be able to see it again after closing this window

Important: This is NOT your regular Gmail password. This is a special app-specific password that only Gold Rush will use. Google generates it specifically for this purpose.

3 Configure Settings 5 minutes

What you're doing:

Creating a configuration file with your email, API key, and job search preferences.

Commands to run:

cd "$HOME/Job Searching" touch config.env open -a TextEdit config.env

Paste this into the file and fill in YOUR details:

# Email Settings EMAIL_ADDRESS=your.email@gmail.com EMAIL_APP_PASSWORD=xxxx xxxx xxxx xxxx # From Step 2 # JSearch API (copy from Job Tracking Dashboard) JSEARCH_API_KEY=your_rapidapi_key_here JSEARCH_API_HOST=jsearch.p.rapidapi.com # Job Search Preferences TARGET_TITLES=Technical Product Manager,Product Manager - Data,Product Manager - Analytics,Senior Product Analyst,Data Product Manager TARGET_LOCATIONS=San Francisco,Remote,Bay Area,Palo Alto,Mountain View MIN_SALARY=100000 PREFERRED_SALARY=120000 # Notification Settings SEND_DAILY_DIGEST=true SEND_IMMEDIATE_PLATINUM=true DIGEST_TIME=07:00 # API Usage Limits MAX_JSEARCH_CALLS_PER_DAY=6 ENABLE_EMAIL_PARSING=true # Company Preferences PREFERRED_COMPANIES=Stripe,Figma,Notion,Databricks,Snowflake,Retool,Airtable,Linear,Vercel,Ramp,Plaid AVOID_COMPANIES=

How to get your JSearch API key:

Open Terminal and run:

cd "$HOME/Job Tracking Dashboard" cat .env | grep JSEARCH

Copy the value after VITE_JSEARCH_API_KEY= and paste it into Gold Rush's config.env

Important: Save and close the file when you're done. Make sure there are no typos in your email or API key.
4 Set Up Job Alerts 10 minutes

Why you need this:

LinkedIn and Indeed will email you when new jobs are posted. Gold Rush reads these emails and parses the jobs automatically. This gives you fresh jobs without hitting API rate limits.

LinkedIn Job Alerts

  1. Go to linkedin.com/jobs
  2. Create Alert #1:
    • Search: "Technical Product Manager"
    • Location: "San Francisco, CA"
    • Click the bell icon ("Set Alert")
    • Frequency: Daily
  3. Create Alert #2:
    • Search: "Product Manager Data"
    • Location: "Remote"
    • Set alert → Daily
  4. Create Alert #3:
    • Search: "Senior Product Analyst"
    • Location: "San Francisco, CA"
    • Set alert → Daily
  5. Create Alert #4:
    • Search: "Product Manager Analytics"
    • Location: "Remote"
    • Set alert → Daily

Indeed Job Alerts

  1. Go to indeed.com
  2. Create Alert #1:
    • Search: "Technical Product Manager"
    • Location: "San Francisco, CA"
    • Click "Email me jobs like these"
    • Frequency: Daily
  3. Create Alert #2:
    • Search: "Product Manager Data"
    • Location: "Remote"
    • Email alert → Daily
  4. Create Alert #3:
    • Search: "Senior Product Analyst"
    • Location: "Bay Area, CA"
    • Email alert → Daily

Critical: Use the SAME email address you put in config.env (Step 3). Gold Rush will read job alerts sent to this address.

6 Schedule Automatic Runs 5 minutes

What you're doing:

Setting up macOS to run Gold Rush automatically at 7:00 AM and 7:00 PM every day. You'll wake up to golden jobs in your inbox without having to do anything.

Create the scheduler file:

cd "$HOME/Job Searching" touch com.yourname.gold_rush.plist open -a TextEdit com.yourname.gold_rush.plist

Paste this into the file:

<?xml version="1.0" encoding="UTF-8"?> <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd"> <plist version="1.0"> <dict> <key>Label</key> <string>com.yourname.gold_rush</string> <key>ProgramArguments</key> <array> <string>/usr/bin/python3</string> <string>$HOME/Job Searching/gold_rush.py</string> </array> <key>StartCalendarInterval</key> <array> <dict> <key>Hour</key> <integer>7</integer> <key>Minute</key> <integer>0</integer> </dict> <dict> <key>Hour</key> <integer>19</integer> <key>Minute</key> <integer>0</integer> </dict> </array> <key>StandardOutPath</key> <string>$HOME/Job Searching/logs/launchd.out.log</string> <key>StandardErrorPath</key> <string>$HOME/Job Searching/logs/launchd.err.log</string> <key>WorkingDirectory</key> <string>$HOME/Job Searching</string> <key>RunAtLoad</key> <true/> </dict> </plist>

Save and close the file.

Install the scheduler:

# Copy to LaunchAgents folder cp com.yourname.gold_rush.plist ~/Library/LaunchAgents/ # Load the job (starts it immediately and schedules future runs) launchctl load ~/Library/LaunchAgents/com.yourname.gold_rush.plist # Verify it's running launchctl list | grep gold_rush

Expected output:

You should see something like: 82756 0 com.yourname.gold_rush

What this scheduler does:

  • Runs Gold Rush at 7:00 AM every day (morning digest)
  • Runs Gold Rush at 7:00 PM every day (evening update)
  • Logs all output to logs/ folder
  • Runs automatically - you don't have to do anything

5. Troubleshooting

Problem: No email received

Check if script ran:

tail -50 logs/gold_rush.log

Check if scheduler is loaded:

launchctl list | grep gold_rush

If not loaded, reload it:

launchctl load ~/Library/LaunchAgents/com.yourname.gold_rush.plist

Problem: Email went to spam

  1. Go to Gmail spam folder
  2. Find the Gold Rush email
  3. Click "Not Spam"
  4. Create a filter: From your.email@gmail.com → Never send to spam

Problem: API rate limit exceeded

Symptom: Error log says "429 Too Many Requests"

Fix: Edit config.env, change:

MAX_JSEARCH_CALLS_PER_DAY=4 # Reduce from 6 to 4

Then reload:

launchctl unload ~/Library/LaunchAgents/com.yourname.gold_rush.plist launchctl load ~/Library/LaunchAgents/com.yourname.gold_rush.plist

Problem: All jobs scored low (<60)

Likely cause: Search terms too narrow, or slow job market

Fix: Expand TARGET_TITLES in config.env

Example: Add "Product Analyst", "Analytics Manager", "Product Operations Manager"

Want to run manually?

cd "$HOME/Job Searching" python3 gold_rush.py

Want to stop the scheduler?

launchctl unload ~/Library/LaunchAgents/com.yourname.gold_rush.plist

To restart:

launchctl load ~/Library/LaunchAgents/com.yourname.gold_rush.plist

Common Error Messages

Error Solution
Authentication failed (Gmail) Regenerate app password in Step 2, update config.env
API key invalid Check JSearch API key in config.env, verify it's correct from Job Tracking Dashboard
Module not found Re-run pip3 install requests beautifulsoup4 python-dotenv
Permission denied Make script executable: chmod +x gold_rush.py
